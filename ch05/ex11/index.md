# 問題5.11

## Nodeでdebugger文を使ってデバッグする方法

Node.jsには標準で組み込みのコマンドラインデバッガが付属しており、`node inspect` コマンドで起動できる。

```sh
node inspect myscript.js
```

このコマンドで実行すると、スクリプトの最初の実行可能な行で自動的に一時停止した状態で起動する。

コード中に `debugger;` という文を書いておくと、その行に到達したときに実行が一時停止し(ブレークポイントを置いたのと同じ効果)、デバッガのプロンプトからその時点の状態を調べたり、続きを1行ずつ実行したりできる。

```js
setTimeout(() => {
  debugger; // ここで実行が一時停止する
  console.log("world");
}, 1000);
```

デバッガが一時停止している間に使える主なコマンド:

- `cont` / `c`: 実行を再開する
- `next` / `n`: 次の行まで実行する(関数の中には入らない)
- `step` / `s`: 次の行まで実行する(関数呼び出しがあれば中に入る)
- `out` / `o`: 現在の関数から抜けるまで実行する
- `setBreakpoint()` / `sb()`: 現在の行にブレークポイントを設定する
- `repl`: その時点のスコープでコードを対話的に実行できるREPLを開く(変数の値を調べるときに便利)
- `backtrace` / `bt`: スタックトレースを表示する
- `watch(式)`: 指定した式の値を監視対象に追加する

例えば`repl`で変数名を打つとその時点での値が表示され、`.exit`でREPLから抜けられる。何もコマンドを打たずにEnterだけ押すと、直前のコマンドが繰り返される。
